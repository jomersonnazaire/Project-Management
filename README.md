# Xceler8 Project Management (Implementation Tracker)

Web app for managing implementation projects (templates, tasks, time, client follow-up, documents) for Xceler8.

- Requirements, QA plan, and design (mockup v0.4, theme tokens): [`docs/`](docs/)
- Stack: React + TypeScript (Vite) front end on Vercel, Node.js 22 + Express + TypeScript API on Azure App Service, MongoDB Atlas.

Application code is added milestone by milestone through pull requests.
